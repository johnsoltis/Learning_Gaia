Code for Soltis 2026, Learning Gaia: A Generative Model Trained on the Gaia Data Release 3 Source Catalog. Please see the paper for more details.

Contains the code for training the model, testing the model, and producing the figures in the paper. Data products are on zenodo (see DOI in paper).

Please note that some of the functions in the code are deprecated. The figure and tables notebooks have gone through multiple iterations. The figure numbering system in the notebook no longer corresponds to the paper, but this is noted in the notebook itself.

I do not promise to keep this code up to date, but I am instead providing it for completeness. I am happy to answer any questions or help address any issues you might have.
